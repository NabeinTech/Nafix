# 🤖 Guide Rapide: NafixAI ChatBot

## ⚡ Démarrage Rapide (30 secondes)

1. **Menu latéral** → Cliquez sur **"Aide IA 💬"**
2. **Posez votre question** (ex: "Comment éviter les ruptures?")
3. **Recevez une réponse claire** avec exemples concrets

C'est tout! 🎉

## 🎯 Utilisation Optimale

### 1. **Comprendre une métrique**
```
Vous: "Pourquoi ce produit a un score de 35?"
Bot: Explique le scoring, vous aide à améliorer
```

### 2. **Obtenir une action**
```
Vous: "Quels produits je dois pousser?"
Bot: Recommande les A+, explique comment les vendre plus
```

### 3. **Valider une décision**
```
Vous: "Je dois augmenter le stock du produit X"
Bot: Analyse la rentabilité et vous dit si c'est bon
```

### 4. **Apprendre la stratégie**
```
Vous: "Comment élever un client Dormant en Champion?"
Bot: Détaille la stratégie de réactivation
```

## ❓ FAQ Rapides

### Q: Le chatbot a accès à mes données réelles?
A: **NON.** Le chatbot explique les concepts. Les données réelles sont dans les 5 onglets du dashboard NafixAI.

### Q: Peux-je faire confiance aux réponses?
A: **OUI.** Basées sur des méthodes statistiques éprouvées. Mais consultez un expert pour décisions majeures.

### Q: C'est en temps réel?
A: **NON.** Le chatbot est un guide statique. Pour données temps réel: consultez le dashboard.

### Q: Je peux exporter la conversation?
A: Pas encore (version 1.0). Vous pouvez copier-coller.
